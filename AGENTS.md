Global guidelines for working on repositories in this directory:
- Please remove all mannered prose.
- When writing code comments:
  - Don't comment what the code does, assume the reader knows the language.
  - Succinct comments where something may be easily misunderstood or incorrect assumptions made. minimal is preferred.
  - Don't refer to any delivery or planning, task items, codenames, etc. Keep the comments relative to the domain.

Workflow:
- ONLY complete work that is documented in `tickets/{repo_name}` where `{repo_name}` is the name of the repository being modified (eg: `tickets/edrolo/0001_fix_foo.md`).
- If the scope of a ticket expands, er towards writing a new ticket rather than expanding the scope.
